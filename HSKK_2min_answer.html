Цель: прямой ответ + одна причина. Формула: 我觉得……，因为……

Цель: ответ + две причины. Формула: 首先……，其次……

Цель: добавить конкретный пример. Формула: 比如…… / 有一次……

Цель: полный каркас и вывод. Формула: 回答 + 原因 + 例子 + 看法 + 总结
